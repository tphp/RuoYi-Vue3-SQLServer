# 优化改造文档目录（03-optimization）

存放性能优化、代码重构、架构改造等文档。

## 目录组织规范

按**业务模块 / 技术领域**建子目录归类，与 `01-requirements`、`02-development` 保持一致。

```
03-optimization/
├── README.md                 # 本文件：规范 + 索引
├── _template-optimize.md     # 优化文档模板（勿删）
└── <模块名>/                 # 每个业务模块 / 技术领域一个子目录
    └── <优化项>-优化.md
```

### 命名规范

- 模块目录：英文小写、短横线分隔，与后端模块名对齐（如 `bizperm`、`apilog`）
- 优化文档：`<模块>-<优化项>-优化.md`，例如 `apilog-异步落库-优化.md`
- 模板：`_template-optimize.md`

### 新增优化文档步骤

1. 在 `03-optimization/` 下新建（或复用）对应模块子目录。
2. 复制 `_template-optimize.md` 到该子目录，重命名为正式文档。
3. 优化前先评估影响面与风险；明确改动范围、验证方式与回滚方案。
4. 优化完成后补充验证结果，并更新下方「文档索引」。
