# 需求文档（PRD） - 接口日志（入站/出站）

> 中文名称：接口日志功能需求文档

> 作者：AI 回溯补录（基于 `ruoyi-apilog` 代码梳理）| 日期：2026-11-17 | 状态：回溯补录（待业务确认）
>
> ⚠️ 本文档为事后回溯：功能已实现（后端），需求描述以现有代码行为为准，待与业务方确认原始意图。

## 1. 需求背景

- 问题 / 机会描述：系统与外部系统双向对接（外部调入、本系统调出），缺少统一的接口报文留痕手段，排障、审计、对账无据可查。

## 2. 需求目标

- 业务目标：入站、出站接口报文全量可追溯，出现问题可快速定位是请求问题还是响应问题。
- 量化指标（如有）：日志写入不阻塞业务请求（异步落库）；超长报文按阈值截断，保护存储与页面加载。

## 3. 需求范围

### 包含

- [x] 入站接口日志采集（全局过滤器，记录请求头/请求体/响应/异常堆栈/IP/UA 等）
- [x] 出站接口日志采集（统一 HTTP 客户端，记录接口名/URL/参数/状态/响应/耗时/异常）
- [x] 敏感信息脱敏与报文截断（`ApiLogUtils.maskSensitive` / `truncate`）
- [x] 日志查询、详情、删除、清空（分页 + 权限）
- [x] 系统监控菜单下的入站/出站日志菜单与按钮权限
- [ ] 前端日志查询页面（**当前缺失，见「疑问与待确认」**）

### 不包含（Out of Scope）

- [ ] 日志检索分析平台、告警通知
- [ ] 日志归档与过期自动转储（当前仅提供手动清空）
- [ ] 分布式链路追踪（Trace/Span 跨服务串联）

## 4. 用户与角色

| 角色 | 使用场景 | 核心诉求 |
|------|----------|----------|
| 系统管理员 | 接口报错后查日志定位问题 | 按接口、时间快速检索到报文与堆栈 |
| 运维/排障人员 | 外部系统反馈调用失败时核对报文 | 请求与响应原文可比对 |
| 接口开发人员 | 联调期间观察报文格式 | 实时可见入站/出站内容 |
| 审计人员 | 事后核查数据交互 | 日志不可随意篡改、敏感字段脱敏 |

## 5. 功能需求

### 功能点1：入站日志采集

- 描述：`ApiInboundLogFilter`（全局过滤器）拦截外部/前端请求，采集请求头、请求体、响应内容、异常堆栈。
- 交互 / 流程：请求进入 → 过滤器解析报文（脱敏、截断）→ `SysInboundLogServiceImpl.record` → 线程池异步写入 `sys_inbound_log` → 响应正常返回。
- 约束条件：
  - 配置开关 `api-log.inbound.enabled`，报文长度上限 `api-log.inbound.max-content-length`（默认 8000 字符）
  - 排除路径：登录/登出/验证码、静态资源、actuator、druid、日志查询接口自身等（`EXCLUDE_PREFIXES`）
  - 请求头仅记录白名单字段且上限 2000 字符

### 功能点2：出站日志采集

- 描述：`ExternalApiClient`（GET/POST JSON/POST Form）在调用外部系统时自动记录请求参数、响应内容、HTTP 状态、耗时与异常堆栈。
- 交互 / 流程：业务代码调用客户端 → `execute()` 捕获结果/异常 → `ISysOutboundLogService.record` 异步写入 `sys_outbound_log` → 非 2xx 抛出含接口名的业务异常。
- 约束条件：接口需维护「接口名称」便于检索；异常不得吞掉（既要落日志也要向上抛）。

### 功能点3：日志查询与维护

- 描述：分页列表、单条详情、按 ID 批量删除、一键清空。
- 约束条件：权限串 `monitor:inboundLog:list/query/remove`、`monitor:outboundLog:list/query/remove`；列表分页由 PageHelper 统一处理。

### 功能点4：菜单与权限

- 描述：「系统监控」目录下新增「出站接口日志」「入站接口日志」两个菜单及查询/删除按钮。
- 约束条件：菜单组件路径为 `apilog/outboundLog/index`、`apilog/inboundLog/index`（**前端页面尚不存在**）。

## 6. 验收标准

- [ ] 调用任一业务接口后 `sys_inbound_log` 产生记录，且请求耗时无可感知增加
- [ ] `ExternalApiClient` 调用外部接口后 `sys_outbound_log` 产生记录；非 2xx 返回时业务方收到明确异常
- [ ] 日志中的密码/密钥等敏感字段为脱敏值，非明文
- [ ] 超长报文被截断，不出现字段超长导致的落库失败
- [ ] 日志列表分页查询、详情、删除、清空按权限生效
- [ ] **点击入站/出站日志菜单页面正常展示**（依赖前端页面补齐，当前不满足）
